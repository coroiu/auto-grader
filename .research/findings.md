# Research Findings

This file documents key discoveries and insights from research activities.

---

## Template for Research Entries

Use this format when documenting research:

```markdown
## [YYYY-MM-DD] Research Topic

**Question/Goal**: What were you trying to understand?

**Key Findings**:
- Finding 1
- Finding 2
- Finding 3

**Sources**:
- [Source name](URL)
- [Source name](URL)

**Implications**:
How do these findings affect the project?

**Next Steps**:
What further research or decisions are needed?
```

---

## Example Entry

## [2026-01-21] Project Template Structure

**Question/Goal**: What's the best way to maintain project context across Claude sessions?

**Key Findings**:
- CLAUDE.md is emerging as a convention for Claude-specific guidance
- Filesystem-based documentation works well with version control
- Separation between research, planning, and implementation helps maintain clarity
- Progress tracking in markdown files provides searchable history

**Sources**:
- Discussion with user about project management patterns
- Common practices in AI-assisted development

**Implications**:
Using this structure should make it easier to maintain long-running projects with Claude while keeping all context version controlled.

**Next Steps**:
Test this template on actual projects to validate effectiveness.
